*An Enterprise AI Transformation Readiness Assessment Tool.*

* **Impact:** Evaluates leadership readiness, technology alignment, skills gap, AI governance, risks, and maps out a transformation roadmap for CTOs/CIOs.
* **Tech:** Python, AI-driven assessment engine, data analytics.

### 2. ⚡ [CogniClean Assistant](https://github.com/mohammadquasif/CogniClean)
*Privacy-First, Local AI-Powered Windows Optimization & Health Engine.*
* **Concept:** A beautiful desktop application designed with Glassmorphism styles that optimizes Windows safely using an entirely offline local LLM.
* **Features:** 12+ safe cleanup workflows, RAM trim, speed tests, voice-control, and 5-min idle auto-shutdown to free memory.
* **Tech:** Python, PyQt6, Ollama (`qwen2.5:0.5b` / `llama3.2:1b`), `psutil`, `pyttsx3`, SQLite, cryptography.
